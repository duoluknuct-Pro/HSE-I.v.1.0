# HSE-I.v.1.0
HSE platform pengelolaan HSE/K3 berbasis digital

HSE Init adalah aplikasi digital terintegrasi untuk membantu perusahaan mengelola sistem Health, Safety & Environment (HSE/K3) secara efektif, efisien, dan terstruktur. Dilengkapi fitur manajemen risiko, izin kerja digital, pelaporan insiden, audit dan inspeksi, pengelolaan sertifikasi, CSMS, kepatuhan hukum, pelatihan, inventaris APD, hingga pemantauan tindakan perbaikan (CAPA). Dengan dashboard dan analitik real-time, aplikasi ini mendukung peningkatan keselamatan kerja, kepatuhan regulasi, serta kinerja HSE perusahaan
